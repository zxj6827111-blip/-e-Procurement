# 核心流程说明

## 1. 内部采购完整闭环

1. 采购经办人发起采购需求，填写品类、组织、预算说明和附件。
2. 系统仅做 Mock 采购方式建议，金额阈值统一标注“客户制度确认”。
3. 项目立项后编制采购文件，文件发布后锁定，版本可追溯。
4. 发布内部公告或定向邀请供应商，供应商完成报名和资料上传。
5. 供应商在报价截止前暂存、提交、撤回或重提报价。
6. 报价截止后自动锁定，按权限展示报价汇总和响应材料。
7. 专家完成回避、纪律和保密承诺确认后独立评分。
8. 系统生成评分汇总和评审报告快照，报告冻结后不得修改实质结论。
9. 非最低价中选必须填写理由并进入定标审批。
10. 审批通过后结果通知、内部公示、合同台账、履约评价、档案归集和审计日志闭环。

## 2. 报价保密流程

- 截止前，供应商只能查看本企业报价。
- 截止前，采购经办人只能查看报名名单和提交状态，不能查看金额和响应文件。
- 截止前，专家不可见报价和响应文件。
- 截止后，按权限查看报价汇总和响应材料。
- 所有查看、下载、导出动作写入审计日志。

## 3. 异常查看审批流程

1. 采购经办人提交异常查看申请。
2. 申请必须填写原因、拟查看供应商、拟查看内容和有效期。
3. 审批通过后只能在限定对象、限定内容、限定时间内查看。
4. 超范围或超时访问被拦截。
5. 查看和下载动作写入异常查看日志。
6. 纪检 / 审计人员可只读查询全过程。

## 4. 专家评审流程

1. 专家通过抽取优先产生，指定和替换必须填写理由。
2. 专家先确认回避关系，再确认纪律和保密承诺。
3. 专家只查看被分配项目和评审材料。
4. 专家之间评分互不可见。
5. 评分提交前可暂存和修改，提交后锁定。
6. 重评必须审批，生成新版本，不覆盖旧版本。
7. 采购经办人不得修改专家评分和实质性评审意见。

## 5. 定标审批流程

1. 系统展示评分汇总和推荐供应商。
2. 非最低价中选时必须填写推荐理由。
3. 定标结果必须进入审批，不能绕过审批直接发布。
4. 审批通过后发送结果通知并留痕。
5. 内部公示规则作为客户待确认项。

## 6. 外部交易备案流程

1. 项目标记为“依法必须外部交易”。
2. 内部公告、内部报名、内部报价、内部专家评审、内部定标入口强阻断。
3. 仅支持外部平台名称和编号登记。
4. 上传外部公告资料和外部中标结果。
5. 完成外部结果备案。
6. 后续进入合同台账、履约节点、供应商评价、档案归集和审计查询。

## 7. 合同履约评价流程

- 本平台不编辑合同正文、不做合同审批、不做合同签署、不做电子签章。
- 合同系统主责合同正文、审批、签署和正式归档。
- 本平台维护采购侧合同台账、履约节点、验收付款记录和供应商评价。
- 供应商评价结果进入供应商档案，可用于后续准入、品类授权、限制名单等风控。

## 7.1 采购订单、收货和结算资料流程

1. 定标审批通过后，采购经办人或集团采购管理人员从项目详情工作台生成采购订单。
2. 订单状态从“待确认”开始，由中选供应商确认后进入“已确认”。
3. 收货验收支持部分收货、全部收货和异常收货。
4. 异常类型固定为数量不符、质量问题、延期交付、资料缺失和其他。
5. 异常收货会把订单状态置为“异常”，并写入审计日志。
6. 供应商评价固定覆盖质量、交付、服务、配合度和价格合理性。
7. 结算资料只登记发票、送货单、验收单和其他资料的上传 / 核验状态，不做付款、资金余额、授信、充值或财务核算。

## 8. 档案归集与审计流程

1. 项目全流程资料自动或手工归集。
2. 系统展示档案完整性和缺失资料。
3. 档案封存后不得随意修改。
4. 补档必须发起申请并留痕。
5. 审计日志不可由普通用户修改。
6. 纪检 / 审计人员可只读穿透查询。

## 9. 本轮修正后的关键流程口径

### 报价截止前项目

“客房一次性用品采购项目”只用于演示截止前保密：

- 供应商可提交、撤回、重提本企业报价。
- 采购经办人只能查看报名名单、提交状态、提交数量和催办入口。
- 集团采购管理人员只能查看提交统计、进度和异常状态。
- 纪检 / 审计人员只能查看流程状态、操作日志和异常查看审批。
- 专家不可见报价、响应文件和供应商报价状态，不产生评审任务。
- 页面不展示专家评分、评审报告、定标审批、合同台账等后续阶段。

### 定标审批中项目

“客房布草集中采购项目”用于演示截止后完整闭环：

- `beforeDeadline: false`，报价已截止并锁定。
- 可展示报价汇总、专家评分、评分汇总、评审报告、定标审批、非最低价理由、合同台账、履约节点、供应商评价、项目档案和审计日志。

### 异常查看审批

异常查看审批必须限对象、限内容、限时间：

- 授权对象外的供应商会被拦截。
- 授权内容外的报价金额或附件下载会被拦截。
- 有效期过后入口失效，需要重新申请。
- 允许、拦截和过期尝试均写入 Mock 审计日志。

### 专家评审

专家本人视角和管理 / 审计视角拆分：

- 专家本人只看本人项目、本人确认动作、本人评分表和本人重评版本。
- 管理 / 审计视角可看专家产生方式、确认状态、评分提交状态、汇总和重评版本。
- 回避确认、纪律确认、保密承诺确认是三个独立动作。

## 10. 第二轮客户评审前流程细化

### 供应商隔离流程

1. 供应商进入项目详情时，只判断本企业是否在邀请或参与范围内。
2. 公告 / 邀请卡片不显示其他供应商名称，只显示“本企业已被邀请 / 未在范围”、其他供应商隐藏和供应商数量。
3. 报名记录只显示本企业报名、资质和状态，可显示报名供应商总数。
4. 截止前供应商只看本企业报价金额、响应文件、撤回和重提入口。
5. 截止后供应商仍只看本企业报价和本企业结果，不看其他供应商报价、文件、排名明细和专家意见。

### 专家评分流程

1. 评分数据按“专家 × 供应商”生成，每名有效专家对每家有效供应商形成一张评分表。
2. `p-award` 当前样机为 2 名专家、2 家供应商，共 4 条 `scoringSheets`。
3. 评分表包含项目、专家、供应商、技术分、服务分、价格分、总分、意见、状态、版本、提交时间和锁定时间。
4. 专家本人页按供应商逐行评分，只显示本人评分和意见。
5. 管理 / 审计页展示专家提交状态、供应商评分汇总、排名、异常、非最低价推荐、重评版本和报告冻结。
6. 当前样机为非盲评；盲评不是一期默认必选，需客户确认后再将供应商名称替换为供应商编号。

### 管理员配置流程

1. 系统管理员只进入工作台、我的待办和基础配置。
2. 管理员工作台只展示组织层级、账号数量、角色、菜单配置、Mock 规则、数据字典和权限边界。
3. 管理员不得查看或修改供应商报价金额、响应文件、合同金额、专家评分、专家意见、定标结果、非最低价理由、履约实质、供应商评价实质和审计日志内容。

### 外部交易备案流程修正

1. 外部交易项目无内部报价截止、无内部报价锁定。
2. 外部交易项目不进入内部公告、报名、报价、专家评审、定标闭环。
3. 正确链路为内部立项、审批留痕、外部编号登记、外部公告资料、外部中标结果上传、外部结果备案、合同台账、履约评价、档案归集和审计查询。

### 档案封存与补档流程

1. 档案完整性检查后形成封存记录。
2. 封存后不得直接修改归档内容。
3. 缺失资料需发起补档申请，填写缺失项、原因、申请人、审批人和状态。
4. 补档审批和补档结果必须写入审计日志。
