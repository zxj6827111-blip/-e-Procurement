## 最终结论

| 场景 | 结论 | 说明 |
|---|---|---|
| PDF 本地业务功能 1:1 等价 | Go | 54 页仅保留“已覆盖 / 部分覆盖 / 不适用”三类状态；本地可实现项已覆盖；剩余“部分覆盖”仅为真实外部系统或客户基础设施资料依赖。 |
| 客户 UAT | Go | 十类角色浏览器验收通过，页面失败 0、API 旁证失败 0、控制台错误 0。 |
| 小范围内部试运行 | Conditional Go | 仅限受控范围，需客户书面接受 SQLite、本地文件、mock adapter 和未真实联调边界。 |
| 正式生产上线 | No-Go | 真实 SSO/OA/ERP/WMS/财务/合同/消息/支付/发票验真/CA/对象存储/病毒扫描/生产数据库/监控备份尚未完成。 |

## No-Go 阻塞项

| 阻塞项 | 当前状态 | 生产影响 | 解除条件 |
|---|---|---|---|
| 真实 SSO/组织同步 | adapter/mock 边界完成，未真实联调 | 无法保证企业身份、组织、离职禁用和审计一致性 | 客户提供 SSO、组织、用户资料并完成端到端联调 |
| OA/流程系统 | 本地审批流完成，未接 OA | 企业审批结果无法回写 | 客户提供 OA 接口、测试账号、回调和状态字典 |
| ERP/财务/支付/授信 | 本地结算和资金模拟台账完成 | 无真实付款、授信、对账和冲正 | 客户提供接口、账期、科目、对账文件和回调 |
| WMS/物流 | 本地发货收货完成 | 无真实仓储和物流状态回传 | 客户提供 WMS/物流接口和单据字段 |
| 合同系统 | 本地合同查看边界完成 | 无真实合同签署、编号和归档 | 客户提供合同接口、模板和签署状态 |
| 消息平台 | 本地站内消息完成 | 无短信、邮件、企微等真实触达 | 客户提供模板、签名、收件规则和失败处理 |
| CA/加解密 | 开标安全边界和 mock 完成 | 不能声明真实电子投标加解密/签章 | 客户提供 CA、证书、验签、加解密接口 |
| 发票验真 | adapter 和税额校验完成 | 不能声明真实发票验真 | 客户提供税控/验真接口和错误码 |
| 文件基础设施 | 本地文件中心完成 | 多实例、合规、病毒扫描、预览水印不可生产化 | 接入对象存储、病毒扫描、预览和水印服务 |
| 生产数据库 | SQLite 过渡 | 并发、HA、备份、容量和审计不满足生产 | 迁移到客户批准数据库并完成恢复演练 |
| 监控告警/备份恢复 | 本地 readiness 和恢复演练完成 | 不代表生产 RPO/RTO | 完成生产同构监控、告警、备份恢复演练 |

## UAT 边界

UAT 可以验证：

1. 采购、供应商、询价、招标、开评标、答疑、专家评审、定标定价、商城、资金、退货、结算、发票、问卷、样板间、开业包、审批流、文件中心和审计链路。
2. 采购管理员、酒店采购、酒店财务、平台运营、供应商管理员、供应商报价人员、专家、财务审核、审计只读、系统管理员十类角色路径。
3. 权限隔离、敏感数据边界、审计留痕和本地 mock adapter 行为。

UAT 不应验证为：

1. 真实 SSO/OA/ERP/WMS/财务/合同/消息/支付/发票/CA 已联通。
2. SQLite、本地文件存储、mock 登录适合正式生产。
3. 测试 adapter 等同真实外部系统。

## 正式生产复评门槛

1. 完成真实 SSO、组织同步、权限禁用和审计回归。
2. 完成正式数据库迁移、备份恢复、HA 和容量验证。
3. 完成对象存储、病毒扫描、预览、水印和下载审计联调。
4. 完成 OA、ERP、财务、WMS、合同、消息、支付、发票、CA 的客户确认范围联调。
5. 完成 HTTPS、Secure Cookie、CORS 白名单、反向代理、安全头和密钥管理。
6. 完成日志、指标、告警、值班、RPO/RTO、应急预案和回滚手册。
7. 客户业务、财务、审计、运维和安全共同签署生产验收。
