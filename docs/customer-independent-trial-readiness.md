# 客户独立试用准备说明

## 1. 试用结论

当前版本可用于客户独立试用。试用方式限定为：不接入客户现有 SSO、OA、ERP、WMS、财务、发票、支付、CA 和对象存储系统，由各角色账号在系统内手动录入、填报、上传材料、提交审批并完成流程流转。

本结论不等同于正式生产上线结论。正式生产仍需完成真实身份认证、正式数据库、正式文件存储、外部系统联调、安全加固、备份恢复和客户验收。

## 2. 已满足的试用目标

- 供应商准入、资料提交、资质审核、准入审批、品类授权可通过页面和接口流转。
- 酒店采购、采购经办、集团采购可创建需求、提交审批、拦截自审、决定采购方式并生成项目。
- 公告邀请、供应商报名、供应商报价、报价文件隔离、截标、锁定报价、比价报告可流转。
- 专家分配、专家评分、评审报告、定标审批、结果通知可流转。
- 履约订单、正确供应商确认、错误供应商拒绝、发货、酒店收货可流转。
- 酒店自采商城下单、供应商确认/发货、酒店收货、财务查看结算和付款状态可流转。
- 结算材料、发票状态、付款状态可用人工登记方式验证。
- 档案生成、补档、封存、审计只读查看可流转。
- 我的待办、流程轨迹、Process Layer 展示/镜像追踪可用于试用说明。

## 3. 本轮已修复的试用阻断项

| 问题 | 修复结果 | 验证 |
|---|---|---|
| 供应商管理员、供应商报价人员不能访问本企业报价文件 | 改为按供应商角色组和 `supplierId` 判断，本企业可访问，其他供应商拒绝 | `tests/m6c-final-security-ops.test.ts` 通过；接口复测 `u11/u12` 200，`u14` 403 |

## 4. 试用账号口径

建议试用时按角色发放账号，不使用系统管理员账号代替业务账号。

| 角色 | 推荐账号 | 试用用途 |
|---|---|---|
| 集团采购管理 | `u1` | 审批、监督采购主流程、查看集团范围数据 |
| 采购经办 | `u2` | 主线采购发起、项目推进、公告、报价、评审、定标、归档 |
| 酒店采购 | `u8` | 酒店需求、自采下单、收货 |
| 供应商管理员 | `u11` / `u14` | 供应商资料、订单确认、隔离边界验证 |
| 供应商报价人员 | `u12` / `u15` | 报名、报价、报价文件隔离验证 |
| 专家 | `u7` | 专家评分和评审边界 |
| 酒店财务 | `u9` | 酒店侧结算查看 |
| 财务复核 | `u13` | 结算、发票、付款状态复核 |
| 审计监督 | `u5` | 只读查看审计、档案、流程轨迹 |
| 系统管理员 | `u6` | 组织、账号、角色、权限配置，不参与采购业务 |

## 5. 试用前运行建议

1. 使用独立 `APP_DATA_DIR`，不要复用开发默认数据目录。
2. 试用开始前做一次目录备份；每天试用结束后备份一次 SQLite 与 files 目录。
3. 对客户说明付款、发票、CA、OA、ERP、WMS、财务接口均为人工登记或合同边界，不发生真实外部交易。
4. 试用中如需重置业务数据，使用空业务数据模式或恢复试用前备份。

## 6. 当前验证记录

- API 全量测试：`46` 个测试文件、`256` 个用例通过。
- M6-C 安全与运维回归：`6/6` 通过。
- Typecheck：API 与 Web 均通过。
- Browser role smoke：9 个角色通过。
- Readiness / backup-restore：本地/UAT 演练通过，正式生产仍为 No-Go。

## 7. 不应对客户承诺的内容

- 不承诺正式生产上线。
- 不承诺真实 SSO、OA、ERP、WMS、财务、发票、支付、CA 已接通。
- 不承诺 SQLite 和本地文件存储满足正式生产要求。
- 不承诺 BPMN 已替代 R8 主执行源。
- 不承诺 Process Layer 是正式流程引擎；当前仅用于展示、镜像和事件追踪。
