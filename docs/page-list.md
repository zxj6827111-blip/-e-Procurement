# MVP 页面清单

| 页面 | 模块 | 使用角色 | 主要字段 | 主要按钮 | 状态控制 | 权限控制 | 审计留痕点 |
|---|---|---|---|---|---|---|---|
| 集团采购驾驶舱 | 工作台 | 集团采购管理人员、采购经办人、纪检 / 审计、系统管理员 | 业务角色展示项目数、待审批、截止临近、专家待评、非最低价、外部备案、档案缺失；系统管理员仅展示配置指标 | 查看评审要点、打开审计日志 | 按项目状态或配置域统计 | 按角色展示不同风险入口 | 查看日志、导出日志 |
| 我的待办 | 工作台 | 全部角色 | 待办事项、关联对象、状态 | 查看、进入处理 | 待处理、审批中、已锁定 | 按角色只显示相关待办 | 待办查看、处理动作 |
| 采购项目列表 | 采购业务 | 集团采购管理人员、采购经办人、供应商、评审专家、纪检 / 审计 | 项目编号、名称、方式、状态、组织、档案完整性 | 进入项目 | 内部项目、外部备案项目 | 供应商和专家只看授权项目 | 项目查看 |
| 项目详情 | 采购业务 | 集团采购管理人员、采购经办人、供应商、评审专家、纪检 / 审计 | 采购方式、节点、经办人、截止时间、金额阈值说明 | 流程节点跳转 | 当前节点、已完成、阻断 | 外部交易项目禁用内部流程 | 节点查看 |
| 采购需求与方式判断 | 采购业务 | 集团采购管理人员、采购经办人、纪检 / 审计 | 需求标题、预算说明、品类、组织、方式建议、外部交易标记 | 提交审批、查看留痕 | 待提交、审批中、已审批 | 采购经办人维护，审计只读 | 方式判断、审批意见 |
| 采购文件 | 采购业务 | 集团采购管理人员、采购经办人、纪检 / 审计 | 文件版本、审核状态、附件、发布状态 | 保存版本、提交审核、发布锁定 | 草稿、审核中、已发布锁定 | 发布后不可直接修改 | 版本变更、发布锁定 |
| 公告 / 邀请与报名 | 采购业务 | 集团采购管理人员、采购经办人、供应商、纪检 / 审计 | 公告范围、邀请供应商、报名状态、资格校验；供应商视角仅显示本企业和供应商数量 | 发布公告、邀请、报名、上传资料 | 报名中、截止、已锁定 | 外部交易禁用；限制名单拦截；供应商不见其他供应商名称和状态 | 公告发布、报名提交 |
| 报价响应 | 采购业务 | 采购经办人、供应商、纪检 / 审计 | 报价金额、响应文件、提交时间、提交状态 | 暂存、提交、撤回、重提、查看汇总 | 截止前可撤回，截止后锁定 | 截止前采购方不可见金额和文件 | 查看、下载、导出、提交 |
| 异常查看审批 | 采购业务 | 集团采购管理人员、采购经办人、纪检 / 审计 | 申请原因、对象、内容、有效期、审批人、状态 | 申请、审批、限时查看 | 待审批、已通过、已失效 | 限对象、限内容、限时间 | 申请、审批、查看、下载 |
| 专家库与专家产生 | 采购业务 | 集团采购管理人员、采购经办人、纪检 / 审计 | 专家分类、状态、回避关系、抽取记录、指定理由、替换原因 | 抽取、指定、替换、通知 | 已抽取、已指定、已替换 | 审计只读；指定和替换必须有原因 | 抽取、指定、替换 |
| 专家评审 | 采购业务 | 评审专家、集团采购管理人员、采购经办人、纪检 / 审计 | 回避确认、纪律确认、保密承诺、专家 × 供应商评分表、意见、版本 | 确认、暂存、提交锁定、申请重评 | 待确认、可评分、已锁定、重评版本 | 专家只看本人评分；管理 / 审计只读查看汇总，不可修改评分和意见 | 评分暂存、提交、重评 |
| 评分汇总与评审报告 | 采购业务 | 集团采购管理人员、采购经办人、纪检 / 审计 | 专家提交状态、总分、排名、异常提醒、报告状态 | 生成报告、预览、冻结、补充说明 | 已生成、已冻结 | 汇总由系统生成，报告冻结后不可改结论 | 生成、冻结、补充说明 |
| 定标审批与结果通知 | 采购业务 | 集团采购管理人员、采购经办人、纪检 / 审计 | 推荐供应商、非最低价理由、审批意见、通知记录 | 提交审批、结果通知 | 待提交、审批中、已发布 | 非最低价理由必填；审计只读 | 审批、通知、公示 |
| 外部交易备案 | 采购业务 | 集团采购管理人员、采购经办人、纪检 / 审计 | 内部立项、审批留痕、外部平台、外部编号、外部公告资料、外部中标结果、合同台账、履约评价、档案和审计查询 | 保存备案、进入合同、审计查询 | 备案中、已备案 | 无内部报价截止、无内部报价锁定；内部公告、报名、报价、评审、定标强阻断 | 备案、资料上传、查看 |
| 合同台账 | 履约与监督 | 集团采购管理人员、采购经办人、供应商、纪检 / 审计 | 合同编号、供应商、金额、状态、合同系统链接 | 登记、查看、关联履约 | 待登记、审批中、执行中 | 不编辑合同正文、不做合同审批和签署；供应商仅看本企业合同，不显示其他供应商名称、金额、状态 | 台账登记、查看 |
| 履约节点与供应商评价 | 履约与监督 | 集团采购管理人员、采购经办人、供应商、纪检 / 审计 | 节点、到期日、验收、付款、评价维度、评分 | 保存评价、查看记录 | 待验收、资料待补、已评价 | 供应商只看本企业；审计只读 | 评价保存、附件归集 |
| 项目档案 | 履约与监督 | 集团采购管理人员、采购经办人、纪检 / 审计 | 档案目录、完整性、缺失资料、封存状态 | 完整性检查、封存、补档申请 | 未封存、已封存、补档中 | 封存后不可随意修改 | 检查、封存、补档 |
| 审计日志 | 履约与监督 | 集团采购管理人员、采购经办人、纪检 / 审计 | 时间、操作人、角色、动作、对象、结果 | 查询、导出 | 只读 | 普通用户不可修改，审计穿透查询 | 查询、导出 |
| 基础配置 | 系统配置 | 系统管理员 | 组织、账号、角色、菜单、字典、Mock 规则、权限边界 | 保存配置、查看说明 | 启用、停用、待确认 | 管理员只维护基础配置，不进入供应商管理和采购实质页面 | 配置变更 |

## 客户评审前修正版补充页面 / 卡片

| 页面 / 卡片 | 修正重点 | 客户评审价值 |
|---|---|---|
| 采购需求与方式判断 | 展示需求名称、部门、申请人、预算金额“客户制度确认”、品类、组织、外部交易判断、建议方式、判断依据、变更理由、审批状态、附件、日志 | 确认采购方式和金额阈值不被系统写死，判断结果可追溯 |
| 报价截止前演示项目 | 客房一次性用品采购项目只展示报名、提交状态、提交数量、催办和异常查看审批 | 消除“截止前却进入定标”的状态矛盾 |
| 截止后定标项目 | 客房布草集中采购项目展示报价锁定、专家评分、评审报告、定标审批、合同履约、档案审计 | 用于讲完整内部采购闭环 |
| 异常查看审批 | 结构化展示申请字段、授权对象、授权内容、有效期、审批意见、实际查看 / 下载次数、日志编号 | 体现限对象、限内容、限时间和审计留痕 |
| 专家本人视角 | 只展示本人项目、本人三个确认动作、本人评分表、本人重评版本 | 避免专家看到其他专家评分和意见 |
| 专家管理 / 审计视角 | 展示专家产生方式、指定理由、替换原因、确认状态、提交状态、评分汇总和重评版本 | 支持采购管理和监督评审 |
| 外部交易误操作拦截 | 点击内部公告、报名、报价、专家评审、内部定标入口时弹窗提示禁止原因 | 明确强阻断不是文字说明 |
| 档案目录模板 | 展示 23 项必备目录项及完整性检查字段 | 便于客户确认一期档案目录 |

## 第二轮客户评审前页面修正

| 页面 / 卡片 | 必须呈现的细化口径 |
|---|---|
| 供应商项目详情 | 公告 / 邀请仅显示本企业是否被邀请、其他供应商隐藏和供应商数量；报名只显示本企业记录。 |
| 报价保密 | 截止前供应商看本企业金额和文件，采购经办人看供应商名称、状态、时间但不看金额和文件，集团可匿名统计，审计只看流程 / 状态 / 日志 / 审批，专家无评审任务。 |
| 截止后供应商结果 | 供应商仍只看本企业报价和结果，不看其他供应商报价、文件、排名明细和专家意见；结果公开范围待客户确认。 |
| 供应商合同 / 评价 | 供应商只看本企业合同、本企业履约节点和本企业评价反馈，不显示其他供应商名称、合同金额、履约状态和评价内容。 |
| 异常查看弹窗 | 授权查看展示文件名、大小、上传时间、Hash Mock、不可见内容、有效期和日志号；未授权供应商、未授权内容、过期均显示拦截结果和日志号。 |
| 专家本人页 | 展示供应商逐行评分表，只包含本人评分和意见；当前为非盲评，盲评需客户另行确认。 |
| 专家管理 / 审计页 | 展示专家提交状态、供应商评分汇总、排名、异常、非最低价推荐、重评版本和报告冻结；不提供修改专家评分入口。 |
| 管理员工作台 | 只展示组织层级、账号数量、角色数量、菜单配置、Mock 规则、数据字典和权限边界，不展示业务项目指标。 |
| 外部交易详情 | 明确无内部报价截止、无内部报价锁定，只走外部交易备案链路。 |
| 项目档案 | 新增封存记录、补档申请，强调封存后不得直接修改，补档需申请、审批和留痕。 |
