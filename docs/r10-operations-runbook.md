# R10 运维手册

版本：R10.0  
日期：2026-06-25

## 1. 日常检查

| 频率 | 检查项 | 方法 | 异常处理 |
|---|---|---|---|
| 每日 | 健康检查 | 访问 `/health` | 若 status 非 `ok`，停止验收并检查日志 |
| 每日 | 数据库完整性 | UAT 可运行 `npm.cmd run r9:readiness` | 若 integrity 非 `ok`，立即备份现场并暂停写入 |
| 每日 | 文件恢复风险 | 检查本地文件目录和 `stored_files` 是否匹配 | 若缺文件，追踪上传日志并恢复备份 |
| 每日 | 审计日志 | 抽查关键操作是否有日志 | 若缺失，暂停相关流程验收 |
| 每次发布 | 全量验证 | typecheck/test/build/readiness/恢复演练 | 任一失败不得发布 |

## 2. 备份与恢复

UAT 本地备份：

```powershell
node scripts/r10-backup-restore-drill.mjs
```

当前演练结果：

| 项目 | 结果 |
|---|---|
| SQLite integrity | `ok` |
| `stored_files` | 源 5 / 恢复 5 |
| 缺失文件 | 0 |
| 源/恢复计数 | 匹配 |
| WAL/SHM | 存在并已复制，生产需数据库原生一致性快照 |

生产注意：

1. SQLite 文件复制只能作为本地/UAT 过渡演练。
2. 正式生产应使用数据库原生备份或停机/静默一致性快照。
3. 对象存储必须单独做恢复演练。
4. 恢复后要抽查文件下载、订单、结算、发票和审计日志。

## 3. 常见故障处理

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `/health` 返回非 ok | 数据库、文件存储或配置异常 | 查看 health readiness checks 和服务日志 |
| 登录失败 | 本地账号错误、SSO 未接入、会话配置异常 | UAT 检查账号；生产检查 SSO 回调和 Cookie |
| 页面空白 | 前端 API 地址错误或 API 不可达 | 检查 `VITE_API_BASE_URL` 和浏览器控制台 |
| 文件下载失败 | 文件元数据存在但物理文件缺失，或权限拒绝 | 核对 `stored_files` 和文件目录，检查角色权限 |
| 供应商越权访问被拒绝 | 正常安全行为 | 记录为权限验收证据 |
| 结算或发票状态不一致 | 流程状态或外部财务未联调 | 暂停生产判断，按业务单据追踪 |

## 4. 日志与审计

必须保留：

1. 登录、登出、认证失败。
2. 文件上传、下载、权限拒绝。
3. 供应商准入、限制、评价。
4. 采购申请、报价、定标、订单、收货、结算、发票。
5. 管理员配置变更。
6. 生产 readiness 警告和失败。

UAT 证据位置：

| 证据 | 路径 |
|---|---|
| 浏览器 UAT | `output/r10-browser-evidence/r10-browser-uat-evidence.json` |
| 备份恢复 | `output/r10-backup-restore/r10-backup-restore-drill-latest.json` |
| R9 备份 | `output/r9-backups/` |

## 5. 生产监控建议

| 指标 | 建议阈值 |
|---|---|
| API 5xx | 任意连续增长需告警 |
| 登录失败率 | 5 分钟内异常增长告警 |
| 文件上传失败率 | 超过 2% 告警 |
| 外部系统调用失败 | 连续 3 次或 5 分钟内超过阈值告警 |
| 数据库连接池 | 接近上限告警 |
| 任务积压 | 超 SLA 告警 |
| 磁盘/对象存储容量 | 超 80% 预警，超 90% 告警 |

## 6. 值班和应急

正式生产前必须指定：

1. 业务负责人：判断是否继续业务流程。
2. 技术负责人：判断是否回滚或修复。
3. 数据库负责人：执行备份恢复和数据核对。
4. 文件存储负责人：处理对象存储和文件恢复。
5. 安全负责人：处理账号、越权、文件安全事件。
6. 客户接口负责人：协调 SSO/OA/ERP/WMS/财务/消息系统。

## 7. 停机和恢复流程

1. 通知业务冻结关键操作。
2. 停止 Web 流量或切维护页。
3. 停止 API 写入。
4. 执行数据库和文件备份。
5. 完成修复或恢复。
6. 运行 health、readiness、关键 API 和浏览器冒烟。
7. 由业务确认恢复后开放流量。
