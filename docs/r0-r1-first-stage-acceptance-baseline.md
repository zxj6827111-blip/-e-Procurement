## 4. R1 验收基线

R1 验收不要求完成最终系统全部能力，但必须达到可 UAT 点击状态。

| 验收域 | 第一阶段必须达到 | 不属于第一阶段的后续内容 |
|---|---|---|
| 全站中文显示 | 主路径标题、菜单、按钮、状态、文件类型、审计动作显示中文业务词 | 完整多语言、正式术语库 |
| 状态中文化 | 前端不得直接暴露 `submitted_locked`、`pending_confirmation`、`awarded_pending_order` 等枚举 | 后端枚举仍可保留英文 |
| 上传体验 | 供应商资质、封样、采购申请附件、采购文件、报名资料、响应文件、结算资料、发票、商品图片使用真实文件选择器 | 对象存储、杀毒扫描、大文件分片 |
| 图片与附件预览 | 图片缩略图/预览，普通附件下载，替换/作废，权限拒绝，文件操作留审计 | 在线 Office 预览、OCR、病毒扫描 |
| 采购申请 | 新增、编辑草稿、删除草稿、取消、提交、审批 | 正式多级审批流引擎 |
| 供应商 | 编辑资料、替换资质、限制/恢复、封样图片 | 完整准入评分表和供应商等级 |
| 报价 | 草稿、提交、撤回、重提、响应文件上传 | 完整应标文件要求和多轮报价 |
| 采购文件 | 创建、修订、发布、作废/停用 | 完整招标文件模板和在线协同编制 |
| 订单 | 确认、变更、关闭、异常收货、全部收货 | 完整发货附件、物流和售后结算影响 |
| 结算资料 | 上传、替换文件、核验、驳回后重传 | 正式结算单、账期、付款、资金流水 |
| 档案 | 快照、检查、封存、补档申请、封存后禁止直接修改 | 法规级电子签章、可信存证 |
| 页面入口 | Dashboard、模块总览、项目工作台、文件中心、供应链商城、权限配置均可自然进入 | 完整任务中心、消息中心 |

## 6. 验收命令

本阶段完成后必须运行：

```powershell
npm.cmd run typecheck
npm.cmd run test:api
npm.cmd run build
```

涉及前端页面和文件/图片交互时，还必须浏览器验证：

- 采购管理员主路径。
- 供应商主路径。
- 酒店采购人员主路径。
- 专家或评审角色。
- 财务或结算角色。
- 审计只读角色。
- 系统管理员边界。

## 7. Go / No-Go 口径

| 判断项 | 第一阶段通过后的判断口径 |
|---|---|
| 客户 UAT | 可进入受控客户 UAT，前提是明确本阶段是 R0+R1，不代表最终系统完成 |
| 小范围内网试运行 | 可做演示/UAT 型小范围试运行；若使用真实业务数据，仍需确认认证、数据持久化、备份和权限策略 |
| 正式投产 | 不可正式投产 |

正式投产仍需 R2-R10 完成数据库、SSO、对象存储、外部系统联调、监控备份、安全测试和最终 UAT。
