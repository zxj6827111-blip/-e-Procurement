# R10 客户集成输入清单

版本：R10.0  
日期：2026-06-25  
用途：列出客户进入正式集成、预生产和生产验收前必须提供或确认的输入。未提供前，不应把本地 Mock、测试适配器或本地文件存储表述为真实集成。

## 1. 身份与组织

| 输入项 | 客户需提供 | 当前系统状态 | 缺失影响 | 验收方式 |
|---|---|---|---|---|
| SSO 协议 | OIDC/SAML/CAS/LDAP 方案、Issuer、Client ID、回调地址、证书 | 仅有本地账号和适配边界 | 无法正式接入统一身份 | 真实 SSO 登录、登出、会话过期、禁用用户回归 |
| 组织同步 | 集团、酒店、部门、岗位、用户、角色映射文件或 API | 现有种子组织与角色 | 权限范围无法与客户组织一致 | 同步后抽样核对组织、用户、角色、数据范围 |
| 权限矩阵 | 采购、供应商、专家、审计、财务、系统管理员权限表 | 已有代码权限模型 | 权限争议无法定责 | 权限矩阵逐项回归，越权访问返回拒绝 |

## 2. 外部业务系统

| 系统 | 客户需提供 | 当前系统状态 | R10 结论 |
|---|---|---|---|
| OA/审批 | 审批发起、待办、回调、撤回、驳回、超时规则 | 本地审批/测试适配 | 可 UAT，不可宣称 OA 已集成 |
| ERP | 供应商、商品、订单、结算、付款接口规范 | 本地业务数据 | 可进入接口设计，未完成真实联调 |
| WMS/物流 | 发货、物流、签收、异常收货接口 | 本地发货收货 | 可 UAT 演示，正式履约需联调 |
| 财务/资金 | 账期、余额、授信、付款、发票校验、税控接口 | 本地结算与资金流水 | 不可作为正式财务系统 |
| 合同系统 | 合同生成、查看、归档、盖章接口 | 仅有订单/合同查看边界 | 正式合同流转未完成 |
| 消息系统 | 短信、邮件、企微/钉钉/飞书模板和回调 | 本地站内消息边界 | 生产通知能力未完成 |

## 3. 文件与安全

| 输入项 | 客户需提供 | 当前系统状态 | 生产前要求 |
|---|---|---|---|
| 对象存储 | Endpoint、Bucket、AK/SK 或 STS、内网访问、生命周期、加密策略 | 本地文件存储 | 必须完成对象存储或客户批准的共享文件服务 |
| 防病毒扫描 | 扫描服务接口、超时策略、失败处理 | 未接入正式 AV | 上传文件生产验收前必须接入或书面豁免 |
| 文件预览/水印 | 可预览格式、在线预览服务、水印规则 | 可上传/下载，预览能力有限 | 涉密文件建议接入水印和访问追踪 |
| 证书与域名 | 正式域名、TLS 证书、反向代理配置 | 本地 HTTP | 生产必须 HTTPS、Secure Cookie、明确 CORS 白名单 |

## 4. 数据库、备份与运维

| 输入项 | 客户需提供 | 当前系统状态 | 生产前要求 |
|---|---|---|---|
| 正式数据库 | PostgreSQL/MySQL/国产数据库选型、连接方式、HA 方案 | SQLite 本地/UAT 过渡 | 正式生产不建议继续 SQLite |
| 迁移窗口 | 初始数据、迁移批次、回滚窗口、冻结期 | 本地脚本可检查完整性 | 需要真实迁移演练和客户签字 |
| 备份策略 | RPO/RTO、备份频率、保留周期、异地策略 | 已完成本地 SQLite+文件恢复演练 | 生产需数据库原生一致性快照和对象存储恢复演练 |
| 监控告警 | 日志平台、指标、告警联系人、值班机制 | 本地日志和 health | 需接入客户监控告警 |

## 5. UAT 数据与验收

| 输入项 | 客户需提供 | 当前系统状态 | 验收建议 |
|---|---|---|---|
| 真实组织样本 | 至少 2 个集团/区域、3 个酒店、多个部门 | 种子数据 | 用真实组织验证数据隔离 |
| 供应商样本 | 准入、受限、不同品类和区域供应商 | 种子供应商 | 验证供应商只能看本企业数据 |
| 商品样本 | 价格、税率、图片、供货区域、服务费规则 | 商城数据和测试商品 | 验证商城选品、下单、结算 |
| 采购项目样本 | 询价、招标、专家评分、定标、收货、结算 | 种子项目和测试闭环 | 用真实业务单据跑通至少 3 条端到端链路 |
| 验收签字角色 | 业务、财务、审计、运维、安全、项目负责人 | 本地报告 | 每类角色给出明确通过/阻塞/豁免意见 |

## 6. 必须明确的 Go/No-Go 输入

1. 客户是否接受小范围内部试运行继续使用 SQLite 过渡。
2. 客户是否已提供正式 SSO、对象存储、数据库和至少一个外部业务系统的测试账号。
3. 客户是否同意未接入真实外部系统时仅判定为 UAT Go，而不是生产 Go。
4. 客户是否提供正式数据脱敏规则、日志留存周期和文件合规要求。
5. 客户是否指定生产回滚负责人、恢复负责人和业务冻结窗口。

## 7. M6-C 生产复评补充输入

日期：2026-06-28

M6-C 已完成本地/UAT 安全、运维、九角色浏览器和 Go/No-Go 收口。正式生产复评前，客户仍需补齐：

| 输入项 | 必须提供的生产证据 |
|---|---|
| SSO | 真实登录、登出、禁用、离职、组织变更、会话过期和审计回归 |
| 正式数据库 | 迁移脚本、容量压测、备份恢复、HA、RPO/RTO 演练 |
| 对象存储与杀毒 | 上传、下载、签名 URL、生命周期、病毒扫描失败处理、恢复演练 |
| OA/ERP/WMS/财务/合同/消息/支付/发票/CA | 字段映射、验签、回调、幂等、错误码、重试和端到端业务回归 |
| 监控告警 | 日志平台、指标、告警阈值、值班联系人、应急演练记录 |
| 安全验收 | 漏洞扫描、渗透测试、数据脱敏、日志留存和客户安全签字 |

未提供上述生产证据时，M6-C 结论保持“客户 UAT Go / 受控试运行 Conditional Go / 正式生产 Conditional No-Go”。
