## 权限控制原则

- 供应商只能查看和维护本企业数据。
- 采购经办人在报价截止前不能查看报价金额和响应文件。
- 专家只能查看被分配的评审项目，专家之间评分互不可见。
- 采购经办人不得修改专家评分和专家实质性评审意见。
- 纪检 / 审计人员只读穿透查询，不修改业务数据。
- 系统管理员负责基础配置，不越权处理采购业务实质内容。
- 多组织用户只能查看授权组织范围内的数据。
- 供应商公告 / 邀请、报名、报价、结果、合同、履约和评价均不展示其他供应商名称和明细；必要时仅展示总数、匿名对象或隐藏提示。
- 当前 Demo 为非盲评专家评审；如客户要求盲评，供应商名称应切换为供应商编号，并同步调整专家页、汇总页和权限说明。

## 第二轮客户评审前权限验收点

| 验收点 | 结论口径 |
|---|---|
| 供应商公告 / 邀请 | 只显示“本企业已被邀请 / 未在范围”和供应商数量，不显示其他供应商名称。 |
| 供应商报名 | 只显示本企业报名记录；其他供应商名称、资质附件、状态隐藏。 |
| 供应商报价 / 结果 | 截止前只看本企业报价、文件、撤回 / 重提；截止后仍只看本企业报价和结果，其他供应商报价和专家意见隐藏。 |
| 专家本人评分 | 按供应商逐行评分，只显示本人评分、意见、版本和锁定状态。 |
| 管理 / 审计评分 | 可只读查看专家提交状态、供应商汇总、排名、异常、非最低价推荐、重评版本和报告冻结。 |
| 管理员 | 只能访问工作台、我的待办、基础配置；不能进入供应商管理或任何采购实质操作。 |
| 外部交易 | 无内部报价截止和内部报价锁定；内部公告、报名、报价、专家评审、定标均强阻断。 |
| 档案封存 / 补档 | 封存后不得直接修改；补档必须申请、审批、留痕。 |
