# 国企酒店集团阳光采购与专家评审管理平台 MVP 产品信息架构

## 1. 定位与边界

本 MVP 样机定位为“集团内部阳光采购与专家评审管理平台”的客户评审版 Demo，用于确认页面、流程、字段、权限和规则，不作为生产级系统。

一期范围聚焦：

- 采购需求、采购方式建议、项目立项、采购文件、公告 / 邀请、报名、报价、报价截止锁定。
- 专家抽取 / 指定 / 替换、回避确认、纪律与保密承诺、独立评分、评分汇总、评审报告。
- 定标审批、结果通知、合同台账、履约节点、供应商评价。
- 外部交易项目备案、项目档案、审计日志和监督查询。

一期明确不建设：

- 不做完整法规级电子招投标交易平台、公共资源交易平台、政府采购交易平台。
- 不替代 ERP、OA、财务、合同、主数据系统。
- 不加入 CA 认证、电子签章、投标文件加密、开标解密、可信时间戳、防篡改存证。
- 不做正式后端业务逻辑、正式数据库落表、正式接口联调。

## 3. 角色入口

| 角色 | 工作入口 | 数据范围 | 评审重点 |
|---|---|---|---|
| 集团采购管理人员 | 驾驶舱、项目、审批、专家、定标、档案 | 集团授权范围 | 管控制度、审批权责、风险闭环 |
| 采购经办人 | 项目流程、供应商、报价、专家、合同、档案 | 授权组织和经办项目 | 截止前报价不可见、资料维护边界 |
| 供应商 | 我的待办、项目、供应商档案、报价、合同履约 | 本企业数据 | 企业数据隔离、报价提交、履约评价反馈 |
| 评审专家 | 我的待办、项目、专家评审 | 被分配项目 | 回避确认、保密承诺、独立评分、提交锁定 |
| 纪检 / 审计人员 | 项目、报价、专家、外部备案、合同、档案、日志 | 授权监督范围 | 只读穿透、异常查看、日志不可修改 |
| 系统管理员 | 工作台、我的待办、基础配置 | 系统配置范围 | 只维护组织、账号、角色、菜单、Mock 规则和权限配置，不进入供应商管理和采购实质内容 |

## 4. 核心流程关系

### 内部公开招采项目

采购需求 -> 采购方式判断 -> 项目立项 -> 采购文件 -> 内部公告 -> 供应商报名 -> 报价响应 -> 报价截止锁定 -> 报价汇总 -> 专家评审 -> 评分汇总 -> 评审报告 -> 定标审批 -> 结果通知 -> 合同台账 -> 履约节点 -> 供应商评价 -> 项目档案 -> 审计日志。

### 询价 / 比选项目

采购需求 -> 方式判断 -> 邀请供应商 -> 报价 -> 比价 / 简化评审 -> 定标 -> 合同台账 -> 履约评价 -> 档案归集。

### 依法必须外部交易备案项目

内部立项 -> 审批留痕 -> 外部平台项目编号登记 -> 外部公告资料上传 -> 外部中标结果上传 -> 外部结果备案 -> 合同台账 -> 履约节点 -> 供应商评价 -> 档案归集 -> 审计查询。

该类项目强阻断内部公告、内部报名、内部报价、内部专家评审、内部定标。

## 5. 客户评审前修正版项目拆分

本轮修正后，Demo 明确拆分为以下项目，避免同一项目同时处于“报价截止前”和“定标审批中”：

| 项目 | 用途 | 状态 | 关键限制 |
|---|---|---|---|
| 客房一次性用品采购项目 | 报价截止前保密演示 | 报价响应中 / 报价截止前 | 不展示专家评分、评审报告、定标审批、合同台账等后续数据 |
| 客房布草集中采购项目 | 截止后完整闭环演示 | 定标审批中 / 截止后 | 展示报价汇总、专家评审、评分汇总、定标审批、合同履约、档案审计 |
| 上海滨江酒店食材供应商比选 | 简化采购方式演示 | 已截止 / 简化评审中 | 演示询价 / 比选路径 |
| 客房改造工程外部交易备案项目 | 外部交易强阻断演示 | 外部交易备案中 | 内部公告、报名、报价、专家评审、内部定标入口全部拦截 |

角色可见数据基于当前用户身份过滤：

- 供应商基于 `currentUser.supplierId` 只看本企业数据。
- 专家基于 `currentUser.expertId` 只看本人被分配项目和本人评分。
- 采购经办人基于经办项目和授权组织范围查看。
- 集团采购管理人员和纪检 / 审计人员在报价截止前不默认查看报价金额和响应文件。
- 系统管理员只维护基础配置，不处理采购实质业务。

## 6. 第二轮客户评审前修正口径

- 供应商项目详情、公告 / 邀请、报名、报价、结果、合同、履约和评价均只展示本企业数据；其他供应商名称、状态、报价、文件、合同、评价和专家意见隐藏，可仅展示供应商数量或匿名统计。
- 专家评分数据按“专家 × 供应商”建模；当前 `p-award` 为 2 名专家 × 2 家供应商，共 4 条评分记录。专家本人看到供应商逐行评分表，但只看本人评分和意见；管理 / 审计视角只读查看专家提交状态、供应商汇总、排名、异常、非最低价推荐和报告冻结。
- 当前 Demo 按非盲评展示供应商名称；如客户确认盲评，可将供应商名称切换为供应商编号，并同步调整页面和权限，不作为一期默认必选。
- 系统管理员只看配置指标和基础配置，不查看或修改供应商报价金额、响应文件、合同金额、专家评分、专家意见、定标结果、非最低价理由、履约实质、供应商评价实质和审计日志内容。
- 外部交易项目无内部报价截止、无内部报价锁定，不进入内部公告、报名、报价、专家评审、定标闭环；仅做内部立项、审批留痕、外部编号登记、外部公告资料、外部中标结果上传、外部结果备案、合同台账、履约评价、档案归集和审计查询。
- 档案封存后不得直接修改；补档必须发起申请、审批并留痕。本轮 Mock 已加入封存记录和 `p-ext` 外部中标结果盖章件补档申请。
