# Sprint 4 Visual Direction

- Product posture: commercial B2B procurement SaaS for hotel group supply-chain operations.
- Visual tone: trusted, restrained, audit-friendly, high information density.
- Primary scene: demand, sourcing, expert review, supplier response, fulfillment, settlement, archive audit.
- Brand system: deep procurement blue, warm gold accent, neutral surfaces, semantic status color, light shadows, compact controls.
- Avoided direction: generic blue-white admin dashboard, decorative hero, broad gradients, large empty marketing sections, page-by-page custom CSS.

## Customer First-View Requirements

- Login shows product identity, trust proof and production/local environment boundary.
- AppShell shows grouped role navigation, current role, environment badge, utility entry and account context.
- Core work pages use summary, next action, status and audit/risk panels rather than plain card grids.
- Tables, filters, forms and empty/error/permission states use the same enterprise component system.

## Sprint Boundary

Sprint 4-8 only covers UI visual productization. Sprint 9-13 production infrastructure and customer integration work remains TODO/blocker unless real customer evidence is supplied later.
