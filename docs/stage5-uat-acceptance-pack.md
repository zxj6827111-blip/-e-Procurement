# 阶段 5 UAT 验收包

## 1. 验收目标

在阶段 1-4 已完成完整业务闭环的基础上，本次 UAT 重点验证：

- 正式账号登录与会话
- 数据持久化与重启留存
- 文件真实上传、留存、下载与权限控制
- 采购主流程可用
- 审计留痕可追溯
- 角色隔离有效

不在本次 UAT 范围：

- 商城、购物车、支付、资金授信
- 真实 SSO、ERP、WMS、财务、OA 联调
- CA、电子签章、投标文件加解密、开标大厅
- PostgreSQL/MySQL 正式迁移

## 3. 角色操作脚本

### 3.1 采购经办人

1. 登录系统。
2. 打开项目工作台。
3. 查看采购申请、供应商范围、报价、订单、收货、结算资料、档案和日志。
4. 对已具备条件的项目生成采购订单。
5. 记录异常收货。
6. 查看文件上传和下载结果。
7. 查看审计日志编号。

验收点：

- 能登录。
- 能看到授权项目。
- 可生成订单、登记收货异常。
- 可查看但不能绕过权限读敏感文件。

### 3.2 集团采购管理人

1. 登录系统。
2. 查看项目工作台和审批相关信息。
3. 读取组织范围内项目。
4. 验证与采购经办人的边界差异。

验收点：

- 可读授权组织内项目。
- 可执行组织范围内审批类动作。
- 不出现 mock 切角色路径。

### 3.3 供应商

1. 登录系统。
2. 进入项目工作台。
3. 仅查看本企业参与的项目。
4. 确认本企业订单。
5. 上传结算资料。
6. 下载本企业上传或授权可见的文件。

验收点：

- 看不到其他供应商数据。
- 只能确认本企业订单。
- 可上传并下载本企业文件。

### 3.4 专家

1. 登录系统。
2. 进入专家评审相关入口。
3. 验证不能进入完整业务工作台。
4. 验证只能访问自己的评审任务。

验收点：

- 无法进入采购工作台主链实操。
- 不能下载未授权敏感文件。

### 3.5 纪检 / 审计

1. 登录系统。
2. 查看项目工作台中的审计视图、档案和日志。
3. 下载有权限的审计材料。
4. 验证只读边界。

验收点：

- 可只读穿透项目和日志。
- 不可修改业务数据。

### 3.6 系统管理员

1. 登录系统。
2. 访问基础配置。
3. 验证不能进入采购业务实操。

验收点：

- 仅可访问配置能力。
- 不可读取完整业务工作台敏感内容。

## 9. 已知风险

1. SQLite 只适用于本地或小规模 UAT 过渡，不适用于正式企业级生产。
2. 当前未接真实 SSO，也未完成企业统一身份、组织和人员同步联调。
3. 当前未形成正式数据库高可用、监控告警和灾备体系。
4. 仍存在部分历史页面和种子文案的旧编码遗留风险，本轮只修 UAT 主路径观感。

## 10. Go/No-Go 结论模板

### 可进入 UAT

满足以下条件即可进入 UAT：

- 全量 `typecheck`、`test:api`、`build` 通过
- 正式登录、文件上传下载、权限拦截、重启留存冒烟通过
- 生产模式下 mock 路径关闭

### 不可直接正式投产

原因：

- 仍使用 SQLite 过渡方案
- 未接真实企业集成系统
- 缺少正式运维监控和数据库级高可用能力

### 正式投产前必须补齐

1. 迁移到正式数据库方案并完成迁移验证。
2. 接入真实身份认证和组织同步。
3. 建立正式日志、监控、备份恢复和灾备方案。
4. 完成正式环境安全加固、证书、反向代理和运维守护配置。
