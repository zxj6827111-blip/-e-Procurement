# Phase 2 Data Dictionary

Phase 2 covers procurement documents, internal announcements, supplier invitations, supplier registration and qualification result metadata. It stays inside the formal MVP boundary: attachment metadata only, no CA, e-signature, bid-file encryption/decryption, trusted timestamp, opening hall, or real external system integration.

## Procurement Document

| Field | Meaning | Notes |
|---|---|---|
| document_id | Procurement document identifier | Generated by backend action |
| project_id | Owning procurement project | External-trade projects cannot create internal documents |
| version_no | Document version number | Editing a locked document creates a new version |
| document_status | draft / reviewing / locked | Published documents are locked |
| review_status | draft / submitted / approved | MVP metadata status only |
| attachment_metadata_json | File metadata list | No physical file storage in Phase 2 |
| previous_document_id | Previous version reference | Filled when a revision is created |

## Announcement And Invitation

| Field | Meaning | Notes |
|---|---|---|
| announcement_id | Internal announcement identifier | Requires a locked procurement document |
| announcement_scope | public_internal / invited_suppliers | Controls supplier visibility |
| announcement_status | draft / published / closed | Registration requires published status |
| registration_deadline_at | Supplier registration cutoff | Checked by backend |
| quote_deadline_at | Later quote cutoff | Used to prepare Phase 3 |
| supplier_id | Invited supplier identifier | Invitation record is notification metadata |
| notification_status | pending / sent | No real SMS/email integration |

## Supplier Registration

| Field | Meaning | Notes |
|---|---|---|
| registration_id | Supplier registration identifier | Unique per announcement and supplier |
| supplier_id | Current supplier enterprise | Supplier role can only see its own records |
| registration_status | submitted / qualified / rejected | Business role can qualify registration |
| material_metadata_json | Registration material metadata | No real file upload in Phase 2 |
| qualification_reason | Qualification decision note | Audit log is required for decision |

## Guardrails

| Control | Backend Result |
|---|---|
| External-trade project creates internal announcement or registration | `EXTERNAL_TRADE_INTERNAL_ACTION_BLOCKED` |
| Restricted supplier submits registration | `SUPPLIER_RESTRICTED` |
| Supplier lacks category authorization | `SUPPLIER_CATEGORY_NOT_AUTHORIZED` |
| Supplier reads other supplier registration | Filtered out by supplier-id scope |
| Announcement without locked document | `PROCUREMENT_DOCUMENT_LOCKED_REQUIRED` |
