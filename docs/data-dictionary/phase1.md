# Phase 1 Data Dictionary

Phase 1 covers supplier management, procurement request, method decision and project initiation. It does not introduce announcement, registration, bid/quote, expert review, award, contract, archive sealing, CA, e-signature, file encryption/decryption, trusted timestamp, or real external system integration.

## Supplier Admission

| Field | Meaning | Notes |
|---|---|---|
| supplier_id | Supplier identifier | Reuses supplier master seed identity in the MVP runtime |
| admission_status | pending / admitted / restricted | Backend policy records audit for mutation |
| category_code | Authorized procurement category | Configurable, not hardcoded threshold logic |
| qualification_status | Qualification summary status | Attachment metadata only, no real file storage in Phase 1 |
| restriction_reason | Reason for restriction list action | Used by later phase entry guards |

## Procurement Request

| Field | Meaning | Notes |
|---|---|---|
| request_code | Business request code | Generated by backend action |
| request_status | draft / submitted / method_decided / project_created | State order is enforced by backend |
| method_rule_id | Selected procurement method rule | References configurable rule seed |
| method_suggestion | Method result from selected rule | No hardcoded amount threshold in Phase 1 logic |
| external_trade_flag | Whether request enters external-trade branch | Used when creating the project |

## Project Initiation

| Field | Meaning | Notes |
|---|---|---|
| source_request_id | Procurement request used to create project | Required for traceability |
| project_status | Internal or external project status | External projects start in external_project_recorded |
| external_trade_flag | Branch indicator | Backend internal action guard still blocks internal bid/review actions |
