## 2. 生产前必须补齐

| 安全项 | 当前状态 | 生产要求 |
|---|---|---|
| SSO | 未接真实 SSO | 接入客户统一身份，验证禁用、离职、组织变更 |
| Secure Cookie | 本地/UAT可不启用 | 生产必须 HTTPS + Secure Cookie |
| CORS | 本地/UAT可放宽 | 生产必须精确白名单 |
| Session Secret | UAT 可本地强随机 | 生产必须客户密钥管理 |
| CSRF | 已有 SameSite 策略边界 | 生产需结合客户域名复核 |
| 文件防病毒 | 未接入正式服务 | 必须接入或书面豁免 |
| 对象存储权限 | 当前本地文件 | 生产必须对象存储最小权限和生命周期策略 |
| 水印/预览 | 能上传下载，预览有限 | 涉密文件建议强制水印和访问追踪 |
| 安全测试 | 仅自动化安全边界测试 | 生产前需漏洞扫描和渗透测试 |
| 日志留存 | 本地审计日志 | 生产需客户合规留存周期和归档策略 |

| 集团采购管理人员 | 授权范围内驾驶舱、工作台、商城 | 未授权组织数据 |
