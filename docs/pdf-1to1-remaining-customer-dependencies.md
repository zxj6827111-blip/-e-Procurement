# PDF 1:1 剩余客户依赖清单

日期：2026-06-25  
口径：以下事项不是本地功能缺口，而是真实企业系统和生产基础设施联调所需资料。当前系统仅完成 adapter、mock/test、配置边界、接口契约和联调清单，不声明真实联调完成。

## 客户待提供资料

| 类别 | 待提供资料 | 当前系统边界 |
|---|---|---|
| SSO/统一身份 | 协议类型、Issuer、Client、证书、回调地址、测试账号、用户禁用规则 | 本地账号、mock 登录、SSO adapter 边界 |
| 组织/主数据 | 组织、酒店、品牌、区域、用户、岗位、供应商主数据字段和同步频率 | 本地种子数据、主数据字段映射位 |
| OA 审批 | 流程编码、节点、审批动作、回调、撤回、驳回和超时规则 | 本地审批流、任务、消息、日志 |
| ERP/财务 | 结算单、科目、付款申请、付款状态、对账、冲正字段 | 本地结算、资金、冲正台账 |
| WMS/物流 | 发货单、物流单、收货回传、异常处理、签收附件字段 | 本地发货、收货、异常和附件 |
| 合同系统 | 合同模板、合同编号、签署状态、归档和下载接口 | 本地合同查看边界 |
| 消息平台 | 短信/邮件/企微模板、签名、收件人规则、失败重试 | 本地站内消息和通知留痕 |
| 支付/授信 | 账户、余额、冻结、释放、支付、退款、授信额度和对账文件 | 模拟资金账户、充值、占用和流水 |
| 发票验真 | 发票验真接口、税率规则、错误码、电子发票下载和验签 | 发票 adapter、税额校验、驳回重传 |
| CA/加解密 | CA 服务、证书、签章、投标文件加解密和验签流程 | 开标安全边界和 mock/test adapter |
| 文件基础设施 | 对象存储桶、访问策略、预览服务、水印、病毒扫描服务 | 本地文件中心、版本、作废、下载审计 |
| 生产数据库 | 数据库类型、账号、网络、备份策略、HA、迁移窗口 | SQLite 仅限本地/UAT 过渡 |
| 运维监控 | 日志平台、指标、告警、值班、RPO/RTO、应急预案 | 本地 readiness 和备份恢复演练 |

## 真实联调前置条件

1. 客户提供测试环境访问白名单、测试账号和回调地址。
2. 客户确认接口契约字段、状态码、幂等键、重试策略和异常处理。
3. 客户确认哪些系统必须端到端联调，哪些系统允许 UAT 阶段 mock。
4. 客户确认文件存储、病毒扫描、水印预览和数据备份方案。
5. 客户确认生产数据库与迁移验收口径。

## 当前 Go/No-Go 影响

| 场景 | 结论 | 原因 |
|---|---|---|
| PDF 本地业务 UAT | Go | 本地业务闭环、权限、追溯和浏览器验收已通过。 |
| 外部接口联调 UAT | Conditional Go | 需客户提供接口资料后才能执行。 |
| 正式生产上线 | No-Go | 真实外部系统、生产数据库、对象存储、病毒扫描、监控备份未完成。 |
